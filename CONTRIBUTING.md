# Contribuir

Relate erros pela página /contribuir, informando registro e evidência; conta GitHub não é necessária. Sugestões entram em fila e não alteram a publicação corrente. Não envie dados de estudantes, contatos pessoais ou documentos privados.

Código: instale dependências com npm ci, use banco PostgreSQL isolado, rode npm run typecheck e npm test. Dados: registre fonte oficial, tipologia, edição, partes esperadas, direitos conhecidos, hash e localização. Preserve texto canônico; sugestões de associação não equivalem a relações oficiais.

Mudanças de dados geram nova publicação imutável. Nunca substitua corpus por fixtures nem marque ator automatizado como humano. Consulte docs/requirements.md para condições de aceite.
